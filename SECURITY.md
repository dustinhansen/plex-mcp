# Security Policy

## Supported versions

Only the latest release is supported. There are no maintenance branches.
Fixes ship as a new release.

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub: **Security → Report a
vulnerability** on this repository. Don't open a public issue for anything
security-sensitive. This server holds a Plex token and, in HTTP mode,
exposes a write-capable endpoint, so give me a chance to ship a fix before
details are public.

This is a one-person project, so response is best effort. You'll typically
hear back within a week. Once a fix is released, disclosure details are
published in the advisory and the changelog.
